Mobile 2025

Reliable statutory inspections, even with no signal.

Case study · Adrien Le Breton

Mobile app for regulatory inspections (periodic statutory checks) of lifting equipment. Technicians manage field interventions even without connectivity, syncing as soon as the network is back.

UPTIME · via Neodev Consulting

01 The need

UPTIME, a software agency in Cesson-Sévigné, needed to equip technicians performing statutory inspections (VGP) of lifting equipment: field work on sites where connectivity is never guaranteed, with strict regulatory traceability.

02 The solution

Reinforcing the team through Neodev Consulting, I built a mobile app designed offline-first: data lives on the device first and syncs to the back-end as soon as the network is available.

  • Offline-first: local SQLite storage with automatic back-end sync
  • Secure authentication and full field-intervention management
  • Modern shared stack: React Native on mobile, NestJS server-side

03 Technologies

  • React Native
  • NestJS
  • SQLite

The results

Technicians no longer depend on the network: inspections are recorded on site and consolidated automatically — no re-entry, no data loss.
